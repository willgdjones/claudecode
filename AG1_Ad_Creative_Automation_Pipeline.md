## 3.2 Tone of Voice Analysis

### Voice Characteristics
| Attribute | Description | Example |
|-----------|-------------|---------|
| **Confident** | Assured but not arrogant | "Clinically shown to close nutrient gaps" |
| **Accessible** | Scientific without jargon | "Hit the bull's-eye on nutrition" |
| **Empowering** | Enables customer success | "Thrive, don't just survive" |
| **Authentic** | Real people, real results | UGC testimonials throughout |
| **Premium** | Quality-focused language | "75+ carefully selected ingredients" |

### Language Patterns
- **Active voice**: "AG1 supports..." not "Support is provided by..."
- **Outcome-oriented**: "Feel energized" not "Contains B vitamins"
- **Inclusive**: "For busy lifestyles" covers multiple audiences
- **Conversational**: Reads like advice from a knowledgeable friend
- **Evidence-based**: "Clinically demonstrated" "NSF certified"

### Words They Use
- Foundational, daily ritual, nutritional safety net
- Thrive, optimize, perform, support
- Clinically shown, science-backed, third-party tested
- Convenient, simple, all-in-one
- Gut health, energy, immunity, digestion

### Words They Avoid
- Cheap, discount, miracle, cure
- Detox, cleanse (too wellness-woo)
- Quick fix, instant results
- Medical claims, disease treatment
- Comparison attacks on competitors

## 3.5 Brand Don'ts

### Never Do
- Make medical or disease treatment claims
- Use "miracle" or "cure" language
- Attack competitors by name in ads
- Use before/after weight loss imagery
- Promise overnight or instant results
- Use excessive exclamation points
- Feature unrealistic body standards
- Skip the science backing
- Use generic stock photography
- Oversimplify complex health topics

### Avoid
- Discount-heavy positioning (protects premium)
- Fear-based health messaging
- Gender-exclusive targeting (inclusive brand)
- Jargon-heavy scientific language
- Comparing to pharmaceutical alternatives
- Celebrity-only testimonials (mix with real users)

## 5.6 Ad Specs Summary

### Static Ads Delivery Checklist

| Element | Spec |
|---------|------|
| **File Format** | JPG or PNG (PNG for transparency) |
| **Resolution** | Minimum 1080px on shortest side |
| **Aspect Ratios** | 1:1 (1080x1080), 4:5 (1080x1350), 9:16 (1080x1920) |
| **Text Limit** | Keep text under 20% of image area |
| **Primary Text** | 125 characters before truncation (optimal) |
| **Headline** | 40 characters (truncates after) |
| **Link Description** | 30 characters |
| **File Size** | Under 30MB |

### Video Ads Delivery Checklist

| Element | Spec |
|---------|------|
| **File Format** | MP4 or MOV (H.264 codec) |
| **Resolution** | 1080x1920 (9:16) or 1080x1080 (1:1) |
| **Duration** | 15-60 seconds (optimal), max 120 seconds |
| **Frame Rate** | 30fps minimum |
| **Audio** | AAC, 128kbps minimum |
| **Captions** | Required (burned-in or .SRT file) |
| **Hook** | Must capture in first 3 seconds |
| **File Size** | Under 4GB |

### Google Ads Specs (Display)

| Format | Dimensions |
|--------|------------|
| Leaderboard | 728x90 |
| Medium Rectangle | 300x250 |
| Large Rectangle | 336x280 |
| Wide Skyscraper | 160x600 |
| Square | 250x250 |
| Responsive Display | Multiple assets (logos, headlines, descriptions, images) |

### Google Ads Specs (Video - YouTube)

| Format | Spec |
|--------|------|
| Skippable In-Stream | 12 seconds - 3 minutes (optimal: 15-30s) |
| Non-Skippable | 15-20 seconds max |
| Bumper | 6 seconds max |
| Aspect Ratio | 16:9 or 1:1 |
| Resolution | 1080p minimum |
